# Bookmark Box

A simple local bookmarks manager built with React.

Save links, organise them by category, search through saved bookmarks,
and delete items you no longer need. Data is stored in localStorage.

## Getting started

```
npm install
npm start
```

Open http://localhost:8080 in your browser.

## Build for production

```
npm run build
```

## Features

- Add bookmark with title, URL, category and optional note
- Search bookmarks by title, URL or note
- Filter by category
- Delete bookmarks
- Persists data in localStorage
- Sample bookmarks loaded on first use
